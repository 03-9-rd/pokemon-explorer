# Pokémon Explorer

A simple interactive data explorer built with **React** that fetches data from the [PokeAPI](https://pokeapi.co/) and allows users to browse, search, and filter Pokémon.

---

##  Features

- Fetches and displays the first 150 Pokémon
- View each Pokémon's:
  - Name
  - Image (sprite)
  - Type(s)
  - ID number
- Real-time search by Pokémon name
- Filter by Pokémon type (Fire, Water, Grass, etc.)
- Responsive UI for mobile and desktop
- Handles loading and error states

---

##  Tech Stack

- React with Hooks
- CSS / Tailwind CSS
- PokeAPI (https://pokeapi.co/)
