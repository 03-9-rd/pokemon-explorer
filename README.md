# Pokémon Explorer

A modern, responsive React app that fetches data from the [PokeAPI](https://pokeapi.co/) and lets users explore Pokémon by name and type.

---

## ✨ Features

- 🔍 Real-time Pokémon search
- 🔢 Displays the first 150 Pokémon with:
  - Name
  - Image (sprite)
  - ID number
  - Type(s)
- 📱 Responsive design (mobile & desktop)
- ⏳ Loading & error handling
- 🔁 Filter by type (Fire, Water, Grass, etc.)

---

## 🛠️ Tech Stack

- ⚛️ React with Hooks
- 💨 Tailwind CSS
- 🔗 PokeAPI

---

## 🚀 Setup & Run Locally

```bash
# Clone the repository
git clone https://github.com/03-9-rd/pokemon-explorer.git

# Move into the directory
cd pokemon-explorer

# Install dependencies
npm install

# Start the development server
npm start
